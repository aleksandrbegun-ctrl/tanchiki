# Танчики

Браузерная игра по мотивам Battle City (NES / Денди). Один HTML-файл, без сборки и зависимостей.

## Как запустить

Откройте `index.html` в любом современном браузере.

## Управление

| Действие         | Клавиши                     |
|------------------|-----------------------------|
| Ехать            | Стрелки или `W` `A` `S` `D` |
| Огонь            | `Пробел`, `J`, `K` или `Z`  |
| Старт / пауза    | `Enter` или `P`             |
| Звук вкл. / выкл.| `M`                         |

На стартовом экране игру можно начать и щелчком по полю.

## Цель

Защитите орла внизу поля и уничтожьте все 20 вражеских танков на уровне.

## Бонусы

Красный мигающий танк оставляет бонус, если в него попасть:

- **Каска** — временный щит.
- **Часы** — враги замирают.
- **Лопата** — стальная стена вокруг орла.
- **Звезда** — улучшение танка (до трёх уровней).
- **Граната** — уничтожает всех врагов на поле.
- **Танк** — дополнительная жизнь.

Рекорд сохраняется в браузере.
